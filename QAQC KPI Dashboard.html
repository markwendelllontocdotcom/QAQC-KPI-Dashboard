About this app

Oxypro QAQC KPI Dashboard & Tracker

What it does

An interactive dashboard for monitoring QA/QC KPIs (MSRA, MIR, WIR, NCR, SOR) across every active Oxypro project, as an easier, visual alternative to opening the Excel workbook directly. It reads the PT (current) and Arc (archived history) sheets straight from your master workbook — QAQC KPI Dashboard - All Projects R0.xlsx — and shows a colour-coded health ring, full category breakdown, and an approval-rate trend chart for each project.

How to use it

  • Click “Reload Latest Data” (or drag the workbook onto the page) the first time to pick the file.
  • After that, one click on “Reload Latest Data” re-reads the same file with today’s numbers — no need to browse for it again.
  • Click any project card to open its full detail, including the “Reload Data” button that refreshes just that project in place.

Your data

Everything runs in your browser, on this computer. The workbook is never uploaded anywhere; the dashboard only remembers which file you picked (within this browser) so it can re-read it quickly next time. This dashboard has no connection to, and makes no changes to, the existing daily scheduled automation.
